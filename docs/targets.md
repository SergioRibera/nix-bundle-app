## Programmatic access

```nix
bundler.formats          # flat list of every format
bundler.linuxTargets     # formats producible when target.os = "linux"
bundler.darwinTargets    # ... darwin
bundler.windowsTargets   # ... windows
bundler.targets.<os>     # grouped form (linux | darwin | windows | any)
bundler.formatOS         # raw { format = "<os>" | "any" | [ "<os>" ... ]; }
```

Use these to drive matrix definitions or per-OS UIs without hardcoding
format names.

## Targets per OS

| OS      | Formats |
|---------|---------|
| linux   | `appimage`, `archlinux`, `brew`, `deb`, `flatpak`, `rpm`, `snap`, `tar.gz`, `tar.xz`, `tar.zst`, `zip` |
| darwin  | `app`, `brew`, `dmg`, `pkg`, `productbuild`, `tar.gz`, `tar.xz`, `tar.zst`, `zip` |
| windows | `exe`, `msi`, `nsis`, `tar.gz`, `tar.xz`, `tar.zst`, `zip` |

Wildcards (`tar.gz`, `tar.xz`, `tar.zst`, `zip`) are host-agnostic and appear
under every OS. `brew` is restricted to linux + darwin (linuxbrew +
Homebrew). Every other format is OS-specific.
